iForget 隐私政策

更新日期：2026年9月24日

iForget（以下简称"本应用"）是一款纯本地记事本应用。我们高度重视您的隐私。本隐私政策说明了本应用如何处理您的信息。

一、信息收集

本应用不收集、不存储、不传输任何个人信息。您创建的所有笔记内容仅保存在您设备的本地存储中，不会上传至任何服务器，也不会与任何第三方共享。

二、信息使用

您输入的笔记内容仅用于在本应用中显示和编辑，不会用于任何其他目的。

三、网络访问

本应用不需要网络连接，不包含任何网络通信功能。所有数据均在本地处理，完全离线运行。

四、数据存储与安全

您的笔记数据以文件形式存储在应用沙箱目录中，仅本应用可访问。卸载应用后，相关数据将被自动清除。

五、第三方服务

本应用不集成任何第三方 SDK 或服务，不包含广告、分析、推送等第三方组件。

六、未成年人隐私

本应用不针对未成年人，但由于不收集任何个人信息，对所有年龄段用户均安全。

七、隐私政策更新

如本隐私政策有更新，我们将在此页面发布修改后的政策并更新日期。
